# CE ARENA — User Journey

## 1. First Visit

Visitor enters CE ARENA.

The homepage immediately communicates:

- What CE ARENA is
- Featured games
- Trending games
- Upcoming tournaments
- Leaderboard
- Community activity
- Latest gaming news

Main actions:

- Explore Games
- View Tournaments
- Join CE ARENA

## 2. Game Discovery

Visitor selects Games.

They can:

- Browse games
- Search games
- Filter by category
- View popular games
- View trending games
- Open a game page

## 3. Game Page

The player sees:

- Game information
- Game description
- Genre
- Platforms
- Statistics
- Related tournaments
- Game leaderboard
- Community discussions

The player can select PLAY or join a tournament.

## 4. Account Creation

When an action requires an account:

Visitor creates an account.

After registration:

Account → Profile → CE ARENA Dashboard

## 5. Player Profile

Player can:

- Edit profile
- Select avatar
- View statistics
- View achievements
- View tournament history
- View games
- View ranking

## 6. Competition

Player opens Tournaments.

They can:

- Browse tournaments
- View tournament details
- Register
- View participants
- View brackets
- View results

## 7. Progression

After playing/competing:

Player earns progression through:

- XP
- Rankings
- Achievements
- Tournament results
- Statistics

## 8. Community

Player can:

- Read posts
- Create posts
- Comment
- React
- Join groups
- Find teammates

## 9. Return Experience

When the player returns:

Homepage can show:

- Personalized games
- Upcoming tournaments
- Ranking position
- Notifications
- Community activity
- Recent games
